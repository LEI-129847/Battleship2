## Reflexão

A ferramenta Qodana conseguiu detetar com sucesso as instâncias do cheiro "Long Parameter List", assinalando os métodos que ultrapassaram o limite estrito de 5 parâmetros. O resultado é extremamente sensível ao valor-limite escolhido (5); passar este limiar para 6 ou 7 reduziria drasticamente os avisos. A principal limitação face às estratégias do livro é exatamente a utilização de um limiar absoluto (5 parâmetros para qualquer método), não sendo relativo à média do sistema em causa.
