# Limitações do Checkstyle

O Checkstyle verifica apenas a forma sintática do nome do parâmetro, por exemplo, se V2 viola a convenção e v2 a respeita. Não consegue avaliar se um nome válido, como x ou valor, é suficientemente significativo no contexto do método. Também não verifica se o parâmetro é necessário, se o método tem parâmetros em excesso, nem a qualidade do desenho do código.
