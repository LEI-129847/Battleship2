O que o Checkstyle não consegue verificar

O Checkstyle só verifica a forma do nome, não se este é significativo: MAX_X cumpre a regra mesmo que não diga nada sobre o que representa. Também não decide se um valor devia ser constante, nem apanha constantes em código que o workflow não analisa, como o que o filtro added ignora.
